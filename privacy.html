Informativa sulla privacy

LaPoupee Backup è uno strumento privato per la protezione dei dati operativi di La Poupée. Non è destinato a utenti esterni.

Accesso a Google Drive

L’autorizzazione OAuth è destinata alla gestione dei file di backup creati dall’applicazione, con il permesso limitato drive.file. Il sistema utilizza le API Google Drive per salvare, elencare, leggere, verificare e rimuovere le copie di backup quando necessario per il ripristino e la conservazione programmata. Non richiede accesso a Gmail, contatti o Google Foto.

Protezione e utilizzo dei dati

I backup possono comprendere dati del gestionale, ordini e altri dati operativi del sito. Il sistema è progettato per cifrarli prima del trasferimento su Google Drive. I dati ottenuti tramite le API Google sono utilizzati esclusivamente per le funzioni di backup, verifica e ripristino autorizzate; non vengono venduti, utilizzati per pubblicità o messi a disposizione di terzi per finalità autonome. Google Drive svolge la funzione di conservazione dei file.

Conservazione e revoca

Le copie sono conservate secondo la politica di rotazione configurata dall’operatore. L’operatore può revocare l’autorizzazione dalle impostazioni di sicurezza del proprio account Google e gestire o eliminare il repository di backup. La revoca interrompe l’accesso, ma non elimina automaticamente le copie esistenti.

Contatti

Per richieste relative a questa integrazione, rivolgersi all’operatore autorizzato di La Poupée tramite l’indirizzo di assistenza indicato nella schermata di consenso Google.

Il trattamento dei dati ricevuti dalle API Google è soggetto alla Google API Services User Data Policy, inclusi i requisiti di utilizzo limitato applicabili.
